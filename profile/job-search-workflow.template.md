# Job Search Workflow

> Copy this file to `job-search-workflow.md` and fill in your targets. Your `job-search-workflow.md` is gitignored.

How the assistant finds and ranks roles for you.

## MANDATORY pre-step: de-dupe against roles you already applied to

Before presenting ANY new roles, filter out anything you have already applied to.

- Check your live `applications.md` log first.
- Optionally cross-check a connected email inbox for confirmation or rejection messages from the same company/role.
- Match on **company + title + location** (titles vary slightly across boards, so compare loosely).
- Drop exact and near-duplicate repostings of the same opening.

Never surface a role you have already applied to as if it were new.

## Ranking criteria

Score and sort surviving roles by:

1. **Fit** — overlap with `profile.md` target roles and strong-fit domains.
2. **Level** — matches your seniority (not too junior, not a stretch you cannot defend).
3. **Location / remote** — matches your stated location or remote preference.
4. **Comp** — meets or beats your minimum if the posting lists a range.

Apply the `sponsorship-filter.md` rules before ranking, so disqualified roles never reach the list.
